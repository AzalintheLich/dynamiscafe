About Dynamis Café

Dynamis Café hosts Dynamis statue maps rebuilt for FFXI private servers that run the 75-era, statue-based Dynamis on LandSandBoat (LSB) or AirSkyBoat (ASB) code (for example, HorizonXI). Each map shows where every statue is, how many mobs it pops and which jobs, and whether it's an HP statue, an MP statue or a normal red-eyes statue. Notorious monsters and nightmare groups are labelled right on the map with what they do.

These maps only fit servers where Dynamis mobs pop from statues. Servers that use the later retail-style Dynamis, where mobs roam the zone instead, won't match them.

The layout follows the classic Dynamis Lounge style: the map, the numbered statue list and the notes side by side on one screen, so nobody has to scroll mid-run.

Built from the server code

These maps are built from the AirSkyBoat 75-era Dynamis spawn data, with floor plans from LandSandBoat, not copied from the old retail maps. That code has changes from retail in some of the Dynamis zones, so a few statues pop different mobs, or the mobs sit in different spots, than the old Dynamis Lounge maps show. These maps follow the server code. Each server can also make its own changes, so if something doesn't match on yours, email contact@dynamiscafe.com.

Map updates

These maps are kept up to date. When new findings turn up in the LandSandBoat or AirSkyBoat server code, or a statue pops something different in game, the maps get corrected and the new versions are posted here. Always grab your maps from this site so you have the latest.

Current version: V6 · last updated November 15, 2026. In this version: every statue, mob and NM that gives a time extension has a red TE badge with its minutes right next to its name in the list.
